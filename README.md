# 古文今说 · Chinese Classics in Modern Chinese

古典文献白话译文项目。纯白话、无障碍阅读。

## 目标

想了解古典文献，却没有或很少古文阅读能力？

这个项目把经典古籍**全部翻译为现代白话文**，不加原文、不加注释、不夹杂古文断句——拿到手就是一篇流畅的白话文章，像读当代作品一样读古籍。

## 特点

- **纯白话译文** — 没有原文／注释／白话混杂的问题
- **按卷/篇分文件** — 方便查阅和引用
- **Markdown 格式** — 可直接阅读，也可配合任意工具处理
- **成体系收录** — 经、史、子、集、神怪，逐步扩充

## 阅读建议

直接在 Markdown 阅读器中打开即可。每个文件的标题标注了原书章节名，方便对照查证。

## 说明

- 译文以流畅可读为首要目标，不追求逐字逐句对译
- 人名、地名、官职名尽量保留原貌，辅以必要语境提示
- 部分罕见字标注拼音（置于括号内）
- 如发现译文的错别字或不通顺之处，欢迎反馈
